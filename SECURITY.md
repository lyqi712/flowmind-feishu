# Security Policy

## Supported versions

The latest `main` branch is the only actively supported public version.

## Reporting a vulnerability

Please do not open a public issue for credentials, authentication bypasses, data exfiltration, unsafe file access, or Agent confirmation bypasses. Use a private GitHub security advisory for this repository and include a minimal reproduction without real secrets or user data.

Immediately revoke any credential that may have been exposed. Do not attach `runtime-data`, SQLite files, browser profiles, or real Feishu exports to a report.
