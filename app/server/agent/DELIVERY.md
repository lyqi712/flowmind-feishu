   - 对比分析

   - 推理链生成
   - 知识融合

4. **tool-orchestrator.mjs** (11.5KB)
   - Chain-of-Thought 推理
   - 工具调用链规划
   - 依赖管理
   - 自适应执行
   - 6个内置工具

5. **conversation-memory.mjs** (9.8KB)
   - 滑动窗口记忆（10轮）
   - 自动压缩和摘要
   - 重要性评分
   - 历史搜索
   - 关键信息提取
   - 导出/导入支持

6. **response-generator.mjs** (9.0KB)
   - 自然语言生成
   - 动态开场白（避免模板）
   - 灵活内容组织
   - 澄清问题生成

## 🔧 使用场景

### 场景1: 知识库问答
```javascript
const agent = new AgentCore();
agent.setDocuments(knowledgeBase);
const response = await agent.processMessage('什么是AI？');
```

### 场景2: 文档对比分析
```javascript
const response = await agent.processMessage(
  '对比一下机器学习和深度学习'
);
console.log(response.analysisData);
```

### 场景3: 写作辅助
```javascript
const response = await agent.processMessage(
  '帮我写一篇关于AI的介绍'
);
```

### 场景4: 连续对话
```javascript
await agent.processMessage('什么是知识图谱？');
await agent.processMessage('它有什么应用？'); // 自动理解上下文
```
